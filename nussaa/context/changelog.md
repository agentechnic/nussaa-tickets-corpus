# Nussaa — Release Notes

Customer-facing release notes for the Nussaa app, published with each store
release. Newest last.

## v4.0 — 2026-01-08
Ramadan pre-order scheduling. Customers can place an order in advance for a
chosen delivery time.

## v4.1 — 2026-01-27
Restaurant search ranking rebuilt. Results now weight distance and preparation
time more heavily than rating alone.

## v4.2 — 2026-02-11
New address picker with map pinning, replacing free-text entry. Saved
addresses are migrated automatically.

## v4.3 — 2026-03-04
Loyalty points balance now shown at checkout, alongside the points earned on
the current order.

## v4.4 — 2026-03-23
Order tracking screen refresh. Driver progress is clearer and the map updates
more often.

## v4.5 — 2026-04-14
Payment provider migration. Card handling moves to the new processor; saved
cards carry over.

## v4.6 — 2026-05-06
Group orders. Several people can add to one basket, and the total is split at
checkout.
